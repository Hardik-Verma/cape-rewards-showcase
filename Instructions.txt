# CAPEVERSE UPDATE GUIDE (v2)

You already have the app deployed! This guide is to update your code to the latest version.

### STEP 1: UPDATE YOUR CODE
1. Open your terminal in your project folder.
2. Pull the latest updates:
   `git pull`
   (If you get an error, download the new ZIP from GitHub and replace your local files).

### STEP 2: UPDATE YOUR .ENV FILE
Open your `.env` file and verify these keys. Do **NOT** remove `REWARD_ROLE_ID`.

```text
# Discord & Base Config
DISCORD_TOKEN=
CLIENT_ID=
GUILD_ID=
REWARD_ROLE_ID=

# Database & Offerwall (REQUIRED)
MONGODB_URI=
BITCOTASKS_URL=
POSTBACK_SECRET=CapeRewards_Secure_8xQw2pL5

# Required Services
BREVO_API_KEY=
IMGBB_API_KEY=
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
JWT_SECRET=
PORT=3000
```
*(Note: `BASE_URL`, `DISCORD_CLIENT_ID`, and `DISCORD_GUILD_ID` are no longer required; just use the ones listed above).*

### STEP 3: COMMIT & DEPLOY
1. Open your terminal in the project folder.
2. Run these commands:
   `git add .`
   `git commit -m "Update: responsiveness and history management"`
   `git push`
3. Go to **Render.com** -> Your Web Service -> Environment -> Update your variables to match the new list above.
4. Render will automatically redeploy the new code.
