# CAPEVERSE UPDATE GUIDE (v3)

### STEP 0: SET UP GIT (If you haven't yet)
If `git pull` or `git commit` doesn't work, you need to set up Git:
1. **Download Git:** Go to [git-scm.com](https://git-scm.com/) and install it.
2. **Configure Your Identity:** Open your terminal in the project folder and run these two commands (replace with your info):
   `git config --global user.name "Your Name"`
   `git config --global user.email "your.email@example.com"`
3. **Now you can use Git commands!**

### STEP 1: UPDATE YOUR CODE
1. Open your terminal in your project folder.
2. Pull the latest updates from GitHub:
   `git pull`
   *(This downloads the latest changes I made and merges them into your files).*
   (If you get an error, download the new ZIP from GitHub and replace your local files).

### STEP 2: UPDATE YOUR .ENV & RENDER
Open your `.env` file and **UPDATE** the names of these keys:
- Change `CLIENT_ID` to `DISCORD_CLIENT_ID`
- Change `GUILD_ID` to `DISCORD_GUILD_ID`

**You MUST also go to your Render.com Dashboard -> Environment and rename/add these variables there so the bot can see them.**

**Your .env / Render variables should look like this:**
```text
# Discord & Base Config
DISCORD_TOKEN=
DISCORD_CLIENT_ID=
DISCORD_GUILD_ID=
REWARD_ROLE_ID=

# Database & Offerwall (REQUIRED)
MONGODB_URI=
BITCOTASKS_URL=
POSTBACK_SECRET=CapeRewards_Secure_8xQw2pL5

# Required Services
BREVO_API_KEY=
IMGBB_API_KEY=
GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=
JWT_SECRET=
PORT=3000
```

### STEP 3: COMMIT & DEPLOY
1. Open your terminal in the project folder.
2. Run these commands:
   `git add .`
   `git commit -m "Update: responsiveness and history management"`
   `git push`
3. Render will automatically redeploy. 
4. **IMPORTANT**: If the bot doesn't start, double-check that you renamed the variables on the Render Dashboard Environment tab.
